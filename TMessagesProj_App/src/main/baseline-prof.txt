# Libre: baseline profile.
# Classes and methods listed here are compiled to machine code when the APK is installed (via
# androidx.profileinstaller, already in the app) instead of being interpreted / JIT-compiled on every
# cold start. Covers startup, the chat list, a chat, the profile and scrolling. AGP expands the
# wildcards against the dex and maps the names through R8.
#   H = hot, S = startup, P = post-startup;  ** = anything, including package separators.
